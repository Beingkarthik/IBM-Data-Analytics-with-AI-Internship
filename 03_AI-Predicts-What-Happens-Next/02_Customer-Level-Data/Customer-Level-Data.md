# Customer-Level Data — AI Predicts What Happens Next

## Objective

The transaction-level dataset contains multiple records for the same customer.

For churn prediction, the data needs to be transformed into a customer-level dataset where each customer appears only once.

This creates a customer-level view of purchasing behavior.

## Customer-Level Features

The customer-level dataset contains:

| Feature | Description |
|---|---|
| Customer_ID | Unique customer identifier |
| Order_Count | Total number of orders placed by the customer |
| Total_Revenue | Total revenue generated by the customer |
| Avg_Order_Value | Average value of the customer's orders |
| First_Purchase | Date of the customer's first purchase |
| Last_Purchase | Date of the customer's most recent purchase |

## Customer-Level Transformation

The transaction-level data was grouped by `Customer_ID`.

The following aggregations were applied:

- Count orders for each customer
- Sum revenue for each customer
- Calculate average order value
- Find the first purchase date
- Find the last purchase date

This produces one row per customer.

## Result

The resulting customer-level dataset contains:

- 364 customers
- 6 customer-level features

The customer-level dataset is used as the foundation for calculating RFM features and predicting customer churn.
