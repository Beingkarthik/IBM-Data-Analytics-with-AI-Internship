# RFM Features — AI Predicts What Happens Next

## Objective

RFM analysis is used to describe customer purchasing behavior using three dimensions:

- Recency
- Frequency
- Monetary

These features help represent customer behavior in a structured form for churn prediction.

## RFM Features

| Feature | Description |
|---|---|
| Recency | Number of days since the customer's most recent purchase |
| Frequency | Number of orders placed by the customer |
| Monetary | Total revenue generated by the customer |

## Additional Feature

The model also uses:

| Feature | Description |
|---|---|
| Avg_Order_Value | Average revenue generated per order |

## Feature Calculation

A lower Recency value means the customer purchased more recently.
