# Model Setup — AI Predicts What Happens Next

## Objective

The objective of the model setup stage is to prepare the customer-level dataset for machine learning.

The project uses Logistic Regression to predict whether a customer is likely to churn.

## Prediction Features

The following customer behavior features were used:

| Feature | Description |
|---|---|
| Recency | Number of days since the customer's last purchase |
| Frequency | Number of orders made by the customer |
| Monetary | Total revenue generated by the customer |
| Avg_Order_Value | Average value of the customer's orders |
