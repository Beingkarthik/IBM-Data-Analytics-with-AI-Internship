# Dataset Analysis

## 1. Dataset Overview

The Masterclass 1 practice dataset is an e-commerce transaction dataset used for learning data analytics fundamentals.

The objective of this stage is to understand the raw data before performing data cleaning and analysis.

## 2. Dataset Columns

The dataset contains the following columns:

| Column | Description | Data Classification |
|---|---|---|
| Order_ID | Unique identifier for an order | Identifier |
| Order_Date | Date on which the order was placed | Date/Time |
| Customer_ID | Identifier of the customer | Identifier |
| Product | Product purchased by the customer | Categorical |
| Category | Product category | Categorical |
| Region | Region associated with the order | Categorical |
| Quantity | Number of units purchased | Numerical |
| Revenue | Revenue generated from the order | Numerical |
| Profit | Profit generated from the order | Numerical |

## 3. Dataset Structure

The dataset represents individual e-commerce transactions.

Each row represents an order, while the columns describe the order, customer, product, category, region, quantity, revenue, and profit.

## 4. Column Classification

### Identifier Columns
- Order_ID
- Customer_ID

### Date/Time Column
- Order_Date

### Categorical Columns
- Product

- Region

### Numerical Columns
- Quantity
- Revenue
- Profit

## 5. Initial Observations

The raw dataset contains different types of information required for business analysis.

The dataset can be used to study sales, product performance, customer behaviour, and regional performance.

Before analysis, the raw data needs to be checked for data-quality issues such as missing values, duplicate records, inconsistent categories, incorrect dates, formatting problems, and unusual values.

## 6. Masterclass 1 Objective

The objective is to transform raw data into clean, analysis-ready data and use the cleaned dataset to generate meaningful business questions.
